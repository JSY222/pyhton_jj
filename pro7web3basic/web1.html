    # 시맨틱 태그(Semantic Tag)는 태그 이름만 봐도 담긴 내용의 역할과 의미를 쉽게 알 수 있도록 만든 HTML5 요소입니다 # 범위를 지정할때 사용하는 것 : div(행 전체), span(일부 영역만) # 웹 접근성 (Web Accessibility) # 정의: 신체적·환경적 제약이 있는 사람도 웹 사이트의 정보를 동등하게 인식하고 이용할 수 있는 환경입니다. # 기준: 국내에서는 국가 표준인 한국형 웹 콘텐츠 접근성 지침 2.2(KWCAG 2.2)를 기준으로 삼고 있습니다 # 웹 표준 (Web Standards) # 정의: 웹을 구성하는 기술(HTML, CSS 등)의 공식 문법과 규칙을 준수하는 것을 말합니다. # 목적: 특정 브라우저(예: 크롬, 엣지, 웨일 등)나 운영체제에 치우치지 않고 누구나 동일한 화면과 기능을 누리게 합니다. # 핵심 요소: W3C 마크업 및 스타일시트 검증 통과, 비표준 기술 제거 등
